Why four capsules

We stopped trying to pick one aesthetic.

DRIFT started because we couldn't commit to a single lane — some days call for a worn-in hoodie, others for something quiet, or loud, or genuinely dressed up. So the line moved with us instead of picking a side.

Every capsule is cut from the same block patterns and the same weight of cotton. The materials stay honest across all four; only the attitude changes.
